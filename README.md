# 황혼의 길드 — THE DUSK GUILD

> 왕들이 침묵하고 별들이 이름을 잃은 시대. 이제 길드가 역사를 기록한다.

**v0.5.0 · 첫날 플레이 가이드 / v0.4 선택의 후일담 / 오리지널 BGM 3곡**

어두운 중세 판타지 일러스트와 양피지형 화면을 기반으로 하는 **페이지형 길드 경영 · 스토리 · 파티 전술 RPG**입니다. PC·태블릿·스마트폰에서 실행할 수 있습니다. 기존 「잔월의 서약」과는 별도 프로젝트입니다.

## 실행

- **웹 최신판(v0.5)**: GitHub Pages에 배포할 `index.html`입니다. 초보자 튜토리얼, 전령 시스템과 기존 음악·전투가 함께 실행됩니다.
- **오프라인판(v0.3)**: `offline.html`은 삽화·오리지널 BGM을 포함한 단독 실행본이며, 신규 전령 시스템은 아직 포함하지 않습니다.
- **개발용 소스**: 이 폴더의 `index.html`을 열거나, 정적 서버/GitHub Pages에 폴더 구조를 유지해 게시합니다. `data.js` → `game.js` → `expansion.js` → `courier.js` → `music.js` → `tutorial.js` 순서로 로드합니다. (별도 `tutorial.css` 포함)
- 브라우저 자동 저장은 환경에 따라 제한될 수 있습니다. 설정 화면에서 JSON 세이브를 내보내기/불러오기 할 수 있습니다.

## 핵심 게임 흐름

1. 길드 이름과 난이도를 설정하고 프롤로그를 시작합니다.
2. 의뢰 게시판에서 메인/지역/특별 의뢰 중 하나를 선택합니다.
3. 전열·중열·후열에 배치할 세 명을 선택합니다. **진형 순서 바꾸기** 버튼을 사용할 수 있습니다.
4. 사전 판단 → 현장 조사에서 각각 한 번씩 결정합니다. 정찰·증언은 집중력·방어·세력에 영향을 줍니다.
5. 턴제 전투에서 **동료 개별 기술**, 방패 결진, 길드 연계기, 약초, 철수를 선택합니다. 적은 다음 행동을 예고하며, 우두머리는 후반에 2단계 패턴을 사용합니다.
6. 승리 후 보상 및 진행 결과를 확인하고 귀환합니다. 하루 경과·유지비는 **결과 확인 시 한 번만** 계산됩니다.
7. 영입, 훈련, 강화, 동료 면담과 개인 이야기, 길드 의회와 경쟁 길드 대응으로 다음 원정을 준비합니다.

## v0.2 패치

### 전투와 안정성

- **5개 직업 전술**: 기사(공격+전열 방어), 궁수(약점 표식), 마도사(주문 관통·의식 차단), 치유사(생존자 치유), 도적(차단과 기습).
- **전열·중열·후열**: 배치 순서에 따라 피해 대상과 보호가 바뀝니다.
- **적의 의도**: 기본 공격·강공격·보호막·의식·광역 공격. 우두머리 2단계 패턴. 직업별 적 상성.
- **유대 전투 보너스**와 **개인 연대기 2편 완료 후 특성 강화**.
- 전투 불능인 동료는 약초·치유 주문으로 즉시 돌아오지 못합니다. 원정 후 치유와 휴식이 필요합니다.
- 정찰/연구/기습 선택이 실제 전투 집중·피해·방어에 반영됩니다.
- **원정 결과 보관 및 복원**: 결과 화면에서 재접속해도 정산 대기 상태를 복원합니다. 하루 비용을 중복 계산하지 않습니다.
- v0.1 JSON·브라우저 저장 데이터는 자동 변환합니다. 진행 중이던 전투도 새 전술 UI로 변환합니다.

### 경영과 캐릭터

- **10명의 동료 × 개인 이야기 2편 = 20편**. 인물의 과거, 선택, 충성·세력 변화, 전용 패시브 해금.
- 동료 면담, 파티 유대, 충성도 저하에 따른 출전 거부와 심한 불화 시 이적.
- 후원 계약: 유리강 상단(정기 수익), 백색 수도원(정기 회복), 왕궁(큰 후원과 높은 의무), 독립 운영.
- 경쟁 길드 **백은의 사자단**: 명성 경쟁, 압박, 의뢰 선점, 대응 정책, 평판 후폭풍.
- 수정 2개를 사용해 장비를 최대 3단계 각인합니다. 단계별 능력치·전투 효과 변화. 철광석·은화도 실제로 사용합니다.
- 길드 운영비, 후원 채무, 연체료, 길드원 피로·부상과 사기.

### 서사

- **5장, 기존 메인 의뢰 15편**의 전개를 유지하면서 사전 판단·현장 조사·전투·후속 기록으로 단계 확장.
- **각 장에 2편씩 총 10편의 고유 특별 의뢰**. 반복 지역 의뢰와 별도로 존재하며, 완료 후 사라집니다.
- 주요 선택과 개인 이야기·후원 계약·동료 관계가 연대기와 사건 대사, 보상, 세력 관계, 결말 문장에 반영됩니다.
- 기존 엔딩 3개를 보강해 후원·동료 완결도·주민 신뢰·경쟁 상태에 따라 후일담이 달라집니다.

- `courier.js` — v0.4 왕국 전령의 6개 장별 사건 + 2개 반복 사건, 선택 비용·세력 변화·후속 정산

## 검증

- Chromium에서 모바일 410px 화면의 시작→원정 편성→두 단계 선택→전투→승리→결과 복원→하루 정산→개인 서사→후원 계약을 브라우저 UI로 검사했습니다.
- 메인 의뢰 15편을 통과시켜 다섯 장과 마지막 결말까지 진행되는 것을 검증했습니다. 자동 진행 검사는 전투의 적 체력을 시험 목적상 낮춰 **스토리 분기 연결**을 검사한 것이며, 실제 난이도로 완주했다는 뜻은 아닙니다.
- 기존 데이터 변환 및 전투 불능 약초 복귀 방지 검사를 통과했습니다.
- 실제 모든 직업·난이도·조합·장기 저장 사례의 완전한 테스트까지 끝난 것은 아닙니다.

## v0.3 — 선술집의 악사 (Original Fantasy Soundtrack)

정통 중세 판타지 선술집을 떠올리게 하는 **오리지널 연주 음악 3곡**을 추가했습니다. 하프/류트풍 발현악기, 목관악기, 피치카토 현악기, 가벼운 타악기를 사용하며, 특정 기존 게임의 멜로디를 차용하지 않습니다.

| 음악 | 장면 | 길이 |
|---|---|---|
| 등불과 주사위 (`audio/tavern.mp3`) | 타이틀 · 길드 회관 · 상점 · 기록 | 약 49초 반복 |
| 잊힌 길의 발자국 (`audio/road.mp3`) | 의뢰 게시판 · 왕국 지도 · 원정 조사 | 약 53초 반복 |
| 잉크와 강철 (`audio/battle.mp3`) | 전술 전투 | 약 47초 반복 |

- 스테이지에 맞게 자동 전환하며 곡 사이 **1.25초 교차 페이드**가 적용됩니다.
- 음악은 브라우저의 자동 재생 정책에 맞춰 **첫 화면 터치/클릭부터** 재생됩니다.
- 타이틀 음악 버튼, 게임 상단의 ♫, `설정 → 판타지 주점의 악사`에서 켜기·끄기와 0~100% 음량을 조절합니다.
- 음악 설정은 `dusk_guild_music_v1`에 별도로 저장하며 기존 게임 저장 데이터 `dusk_guild_save_v1`는 수정하지 않습니다.
- 단일 HTML은 3곡 음원을 포함하여 인터넷 연결 없이 재생 가능합니다. 개발자 소스는 외부 mp3 파일을 참조합니다.
- 악보 및 재현용 코드: `scripts/compose_bgm.py` (General MIDI 사운드폰트로 원본 음표 데이터를 렌더링). **사운드폰트는 소스 배포에 포함하지 않습니다.**
## v0.5 — 초보 길드장을 위한 첫날 안내

- 새 게임 시작 후 길드 회관과 게시판에 **첫 원정 안내 카드**가 표시됩니다. 주요 액션 버튼이 메인 의뢰와 원정대 편성 화면으로 직접 연결됩니다.
- 원정대 편성, 사건 판단, 현장 조사, 전술 전투, 결과 정산 화면에 **상황별 팁**을 추가했습니다.
- 은화·명성·사기·체력·피로·전투 집중 등 주요 개념을 설명하는 **초보 길드장 안내서(4개 탭)**를 추가했습니다.
- 플레이 도중 안내를 접어도 화면 아래의 **? 도움말**로 다시 볼 수 있습니다. 기존 진행 세이브는 안내를 자동으로 접고 시작하며 필요하면 다시 열 수 있습니다.
- 새 게임/첫 의뢰 안내/편성 이동/안내 접기/도움말 표시/기존 세이브 기본 동작을 모의 UI 환경에서 검증했습니다.
- **참고:** 오프라인 `offline.html`은 기존 v0.3 판입니다. 웹 버전에만 v0.5 안내가 적용됩니다.

## v0.4 — 왕국의 전령 · 선택의 후일담

- **6개의 장별 고유 사건**과 **2개의 반복 가능한 일상 사건**을 길드 회관에 추가했습니다.
- 사건마다 서로 다른 두 가지 선택이 있고, 즉시 지불하는 은화·세력 신뢰 변화와 2~3일 뒤 받는 성공/실패 결과가 다릅니다.
- 후속 결과는 사건의 위험도에 더해, **보고 시점의 길드 사기, 명성, 관련 세력 평판, 경쟁 길드의 압박**에 따라 결정됩니다.
- 선택과 후일담은 **황혼의 기록** 및 길드 연혁에 남습니다. 기존 저장 기록도 계속 불러올 수 있습니다.
- 테스트: 첫날 사건 표시 → 선택 → 은화·평판 갱신 → 제3일 후속 정산 → 기록 보관을 JavaScript 모의 환경에서 검사했습니다. 모바일 브라우저 전체 플레이 검증은 아직 하지 않았습니다.
- **참고:** `offline.html`은 v0.3 버전으로 유지됩니다. v0.4 기능은 GitHub Pages용 분리 소스에 우선 추가했습니다.

배포 후 주소: https://drink3412-byte.github.io/dusk-guild/

- `audio/`에 오리지널 MP3 3곡, `assets/`에 게임 삽화 16개가 있습니다.
